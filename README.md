# Cursor Native API

在 Cursor 原生聊天中使用自己的模型服务，支持 OpenAI 兼容接口。

## 安装

1. 下载本扩展的 VSIX 安装包。
2. 在 Cursor 的 IDE 窗口按 **Ctrl+Shift+P**，输入 **VSIX**。
3. 选择 **Extensions: Install from VSIX…（扩展：从 VSIX 安装…）**，打开安装包。
4. 如果 Cursor 提示“重新启动扩展”，点击该按钮。
5. 首次安装会打开配置页。点击 **添加服务**，填写服务地址和 API Key。
6. 点击 **读取模型**，勾选需要的模型并添加；也可以手动填写模型 ID。
7. 点击 **保存全部配置**。
8. 正常退出全部 Cursor 窗口，稍后重新打开，完成首次接入。
9. 在聊天框的模型菜单中选择已添加的模型。

配置入口：**Cursor 设置 → Models → 配置模型服务**。首次接入完成前，也可以通过命令面板搜索“配置模型服务”。

## 配置服务与模型

每个服务分别保存地址、密钥和模型。多个服务的模型可以同时出现在聊天菜单中；同名模型会显示所属服务名称。

读取模型后，可以搜索、勾选并批量添加。每张模型卡片可以修改显示名称、推理强度选项和默认强度，也可以填写上下文长度与最大输出；留空则使用服务商默认值。读取模型时，服务商声明的这两个数值会自动填入，已手填的值不会被覆盖。

**保存全部配置**会统一保存所有服务的更改，包括删除的服务和模型。切换正在编辑的服务会保留尚未保存的内容。保存不会改变当前对话已选择的模型；新建子代理沿用父对话的模型与所属服务，恢复子代理时继续使用它原来的选择。

添加的模型只显示在聊天框的模型菜单中，Cursor 设置里的官方模型列表保留原来的内容。可以随时切换使用官方模型和自己的模型服务。

API Key 保存在编辑器安全存储中。密钥已保存时，输入框留空会保留原 Key；点击 **显示** 可以查看当前服务保存的 Key，再次点击隐藏。

使用 OpenCode Go 订阅时，Base URL 填 `https://opencode.ai/inference/go/openai/v1`。插件会为每个对话携带稳定的 `x-opencode-session` 请求头；不填 `/go` 会走按量计费接口。

## 推理强度

在聊天框的模型菜单中找到模型，点击 **Edit** 调整当前对话的推理强度。

配置页会自动识别服务声明的选项。需要自行指定时，在模型卡片中选择 **自定义选项**，填写接口发送值和显示名称。发送值保留大小写。

选择“默认”时由服务决定；聊天中的选择优先于配置页设置的默认强度。

模型卡片中的“测试连接”会发送一条简短请求，可能产生服务费用。

## 更新

插件每天启动后会自动检查 GitHub Releases，发现新版本时提示“安装并重启”。也可以按 **Ctrl+Shift+P** 搜索“检查扩展更新”手动触发。

更新只替换插件本身；接入补丁在下次启动时按新版本重新安排，如果提示需要退出 Cursor，按提示完成一次即可。

插件更新可以直接覆盖安装。如果 Cursor 提示“重新启动扩展”，点击该按钮，再按配置页提示完成接入。

Cursor 更新后会重新识别接入结构。兼容时会安排接入；结构变化时，需要更新插件。服务配置会保留。

安装及升级插件后会关闭 Cursor 自动更新，插件启用期间保持关闭。需要更新 Cursor 时，可以手动安装新版。卸载插件后，可在 Cursor 设置中自行恢复自动更新。

已停用的模型服务接入在插件升级后继续保持停用。

## 停用与卸载

1. 打开配置页底部的 **扩展管理**。
2. 点击 **停用模型服务**。
3. 正常退出全部 Cursor 窗口，稍后重新打开，完成停用。

停用后保留服务配置。重新启用时，可以在命令面板打开“配置模型服务”，点击“完成安装”。

卸载前先完成停用，再到 IDE 的扩展面板找到 **Cursor Native API**，点击 **齿轮 → 卸载**，按 Cursor 提示操作。

## 适用范围

当前提供 Windows x64 预览版，已在 Cursor **3.30.8** 上完成本版离线接入验证。其他版本按实际接入结构判断兼容性。

本扩展为社区项目，与 Cursor 官方无隶属关系。

配置界面参考 [Kilo Code](https://github.com/Kilo-Org/kilocode) 的自定义服务与模型卡片交互。
