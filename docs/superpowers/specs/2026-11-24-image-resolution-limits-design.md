# 图片分辨率上限补丁设计

日期：2026-11-24
状态：待确认

## 背景

Cursor 3.30.14 在输入框附件管线里固定压缩图片：

- `workbench.desktop.main.js` / `workbench.glass.main.js` 的 `ImageUtil` 中，`1024*1024` 为字节预算，`1024` 为长边上限。
- 超过 1MB 的图片会经 canvas 缩到长边 1024px，再以 PNG 或 JPEG 重新编码；仍然超过 1MB 时按 0.8 步长继续缩小。
- 发送阶段，本地运行时 `cursor-local-agent-runtime/dist/main.js` 与官方 Agent Host 共用同一套图片处理，长边上限 1024px、字节预算 1MB。

因此高分辨率截图在放进输入框时就已经变成 1024px，官方模型和自定义模型都受影响。

OpenCode 的服务端 `@opencode/Image` 默认值是 `maxWidth: 2000`、`maxHeight: 2000`、`maxBase64Bytes: 5242880`、`autoResize: true`。本补丁对齐这组值。

## 目标

- 自定义模型链路：输入框保留长边最多 2000px、原始字节最多 5MB 的图片，发送时不再被压回 1024px。
- 官方模型链路：发送阶段仍按 Cursor 默认 1024px / 1MB，不改变官方行为。
- 补丁在 Cursor 版本变化导致签名不匹配时明确拒绝，不产生半应用状态。

## 非目标

- 不修改 Agent Host 的图片处理。
- 不新增设置项或 UI；上限固定为 2000px / 5MB。
- 不改变模型目录、请求路由、工具链或鉴权逻辑。
- 不处理 WebP 专用路径的 1280px 上限（仅截图常见的 PNG/JPEG 走通用路径）。

## 方案

采用方案 A：输入框上限 + 本地运行时上限一起放宽，Agent Host 保持原样。

### 1. 输入框附件上限

在两个 workbench bundle 中匹配结构：

```text
<bytesVar>=1024*1024,<maxUploadVar>=10*1024*1024,<sideVar>=1024,<miscVar>=50
```

把 `<bytesVar>` 的值改为 `5242880`，`<sideVar>` 的值改为 `2000`，其余常量不动。

匹配必须恰好一次，否则拒绝应用。

### 2. 本地运行时发送上限

在 `cursor-local-agent-runtime/dist/main.js` 中：

- `function MF(e,t,n=1024)` → `n=2000`
- `const OF=(e,t,n=1024)=>MF(e,t,n)` → `n=2000`
- `,AF=1048576,` → `,AF=5242880,`

匹配必须各恰好一次，否则拒绝应用。

### 3. 版本与补丁管理

- 新增 `adapters/image-limits.cjs`，负责上述匹配与替换。
- 在 `adapters/cursor-local-agent.cjs` 的 `matches()` 中增加图片签名校验。
- `REVISION` 从 47 升到 48，扩展版本升到 0.10.6。
- 支持已测试的 3.30.8 与 3.30.14；未知版本如果签名不匹配则明确报错。

## 风险与取舍

- 自定义模型的图片 token、延迟和请求体都会增加；2000px 对齐 OpenCode，属于可控范围。
- 部分第三方模型可能限制图片尺寸或大小；超过限制时仍需用户裁剪。
- 输入框上限是全局的，官方模型的预览也会保留高清图；但官方模型发送时仍被 Agent Host 压回 1024px。
- Cursor 升级后压缩变量名可能变化；结构匹配和“恰好一次”校验用于尽早失败，而不是误改。

## 验证

1. 对 3.30.8 原始备份和 3.30.14 安装目录分别生成补丁计划，14 个文件全部通过解析。
2. 运行现有 gate、隔离、工具链验证脚本。
3. 安装 0.10.6，应用修订 48，确认 `status` 为 `applied`。
4. 重启 Cursor，附着一张大于 1MB 的高分辨率截图发给自定义模型：
   - 工作区 `images` 目录中的附件长边应为 2000px；
   - 本地运行时日志不应再出现把该图压到 1024px 的 resize 记录；
   - 请求成功返回。
5. 代码检查确认 Agent Host 的 1024px / 1MB 逻辑未变。

## 范围

仅自定义模型发送链路；官方模型发送链路保持 Cursor 默认。
